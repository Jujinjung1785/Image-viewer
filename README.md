# Image Viewer

내 컴퓨터의 그림 파일과 DICOM 의료영상을 브라우저에서 보는 뷰어입니다.
**`image-viewer-single.html` 파일 하나**로 동작하며, 설치할 것도 인터넷 연결도 필요 없습니다.
그림은 어디에도 업로드되지 않고, 이 컴퓨터의 브라우저 안에서만 읽어서 보여 줍니다.

## 사용 방법

1. `image-viewer-single.html`을 내려받습니다. (저장소의 **Code** → **Download ZIP**, 또는 파일을 열고 **Download raw file**)
2. 탐색기에서 파일을 **더블클릭**하면 브라우저에서 열립니다. Chrome 또는 Edge를 권장합니다.
3. **📁 폴더 열기**로 그림이 있는 폴더를 고르거나, 폴더·파일을 화면에 **끌어다 놓습니다**.

## 기능

- 확장자와 관계없이 파일 내용을 보고 그림인지 판단
  (JPEG, PNG, GIF, WebP, BMP, TIFF, ICO, AVIF, SVG, DICOM)
- 확대·축소 배율과 보던 위치를 유지한 채 다른 그림으로 넘기기
- 작은 그림도 화면에 꽉 차게 보기 (맞춤 / 너비 맞춤 / 100%)
- DICOM 의료영상
  - 비압축, RLE, JPEG Baseline, JPEG Lossless, Deflate
  - 밝기·대비(W/L) 조절, 여러 장이 든 파일(다중 프레임)
- 다중 화면 (1~16개)
  - 시리즈별로 위치 동기화 (DICOM 3차원 위치 정보 사용)
  - 다른 화면이 보고 있는 단면을 색깔 기준선으로 표시
  - 클릭한 위치를 다른 화면에서 찾아 십자로 표시
  - 화면 닫기 · 다시 열기, 확대 동기화, W/L 동기화
- 편집 (**✏ 편집** 버튼, 단일 화면과 다중 화면 모두 — 다중 화면에서는 선택한 창의 그림을 편집)
  - 사각형 또는 자유 모양으로 영역을 골라 안쪽 또는 바깥쪽 지우기 (지운 곳: 투명 · 검정 · 흰색)
  - 선 · 사각형 · 원 · 타원 넣기: 선 색, 굵기, 선 종류(실선 · 파선 · 점선 · 일점쇄선)
  - 도형 안쪽 채우기 켜기·끄기, 채우기 색, 투명도 0~100 (0 = 불투명, 100 = 완전 투명)
  - 글자 넣기: 크기와 색 선택, 더블클릭으로 고치기
  - 넣은 도형·글자 골라서 옮기기 · 바꾸기 · 삭제, 되돌리기 · 다시 실행
  - **PNG로 저장**: 원본과 같은 폴더에 `원본이름_편집.png`로 저장. 같은 이름이 있으면 `_편집(2).png`, `_편집(3).png`처럼 번호를 붙여 **절대 덮어쓰지 않음** (원본도 그대로, 작은 의료영상은 선명하게 크게 저장)
    - "폴더 열기"로 연 그림만 원본 폴더에 저장됩니다. 끌어다 놓기·파일 열기로 연 그림은 저장 위치를 고르는 창이 뜹니다.
    - 파일 하나짜리 버전은 처음 저장할 때 브라우저가 "파일 수정 허용"을 한 번 묻습니다.
  - 편집 내용은 그림(DICOM은 장·프레임)마다 하나로, 단일 화면과 다중 화면에서 함께 보임

## 조작

| 동작 | 단일 화면 | 다중 화면 |
|---|---|---|
| 다음 / 이전 | `→` `←` | 휠, `↓` `↑` |
| 확대 / 축소 | 휠, `+` `-` | `Ctrl` + 휠, `+` `-` |
| 화면에 맞춤 | `0` | `0`, 더블클릭 |
| 그림 이동 | 왼쪽 드래그 | 왼쪽 드래그 |
| DICOM 밝기·대비 | 오른쪽 드래그, `A` 자동 | 오른쪽 드래그, `A` 자동 |
| 다중 화면 켜기·끄기 | `M` | `M` |
| 전체 화면 | `F` | `F` |
| 편집 켜기·끄기 | `E` | `E` |
| 편집: 되돌리기 / 다시 실행 | `Ctrl`+`Z` / `Ctrl`+`Y` | `Ctrl`+`Z` / `Ctrl`+`Y` |
| 편집: 선택한 도형 삭제 | `Delete` | `Delete` |
| 편집: 이동 도구 / 선택 도구 | `H` / `V` | `H` / `V` |

## 보안과 개인정보

- 그림 파일을 어디에도 보내지 않습니다. 페이지가 외부 서버와 통신하지 못하도록 막혀 있습니다(CSP).
- 외부에서 프로그램 코드를 받아오지 않습니다. 필요한 라이브러리는 모두 이 파일 안에 들어 있습니다.
- 브라우저에 저장하는 것은 확대 배율·편집 도구 같은 화면 설정과 마지막으로 연 폴더뿐입니다.
- 편집 내용은 메모리에만 있다가, **PNG로 저장**을 누를 때만 원본 폴더에 새 파일로 만듭니다. 기존 파일(원본 포함)은 절대 수정·삭제·덮어쓰기하지 않습니다.
- 폴더를 열 때 Chrome/Edge가 "파일을 보고 복사하도록 허용하시겠습니까?"라고 묻는 것은 모든 웹페이지에 똑같이 나오는 브라우저 기본 안내입니다. 이 뷰어는 그림을 화면에 보여 주려고 읽기만 하며, 다른 곳으로 복사하거나 보내지 않습니다.
- 환자 정보 보호를 위해 DICOM의 환자 이름은 화면에 표시하지 않습니다.

## 한계

- 브라우저 보안 규칙 때문에 그림 **한 장만 골라서 같은 폴더의 다른 그림을 볼 수는 없습니다.** "폴더 열기"나 끌어다 놓기를 사용하세요.
- Firefox에서는 폴더를 고를 때 "업로드" 문구가 나오지만, 실제로 업로드되지는 않습니다.
- 지원하지 않는 형식: HEIC, JPEG XL, PSD, DICOM의 JPEG 2000 · JPEG-LS · 12비트 JPEG
- 한 파일에 여러 장이 든 최신 DICOM(Enhanced CT/MR)은 보이지만 위치 동기화는 되지 않습니다.
- 저장하지 않은 편집은 다른 폴더를 열거나 창을 닫으면 사라집니다 (닫기 전에 확인 창이 뜸).

## 서버 버전 (선택)

`index.html`, `serve.py`, `dicom.js`, `multiview.js` 4개 파일로 된 서버 버전도 있습니다.
[Python 3](https://www.python.org/downloads/)으로 `python serve.py`를 실행하면, 윈도우 폴더 선택 창을 쓰고
그림 한 장만 골라도 같은 폴더의 다른 그림을 볼 수 있습니다. 이 컴퓨터(127.0.0.1)에서만 접속됩니다.
